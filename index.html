                PIPELINE / 02_ICEBERG.PY
                
Historical tables with catalog metadata

                

                  Spark reads both Bronze datasets and creates two Iceberg
                  tables through a Hadoop catalog, then runs historical SQL
                  aggregations.
                

                
    
                  
  • Snappy-compressed Parquet data files
    • 
                  
  • REES46 events and Criteo clicks tables
    • 
                  
  • Batch analytics and schema evolution
    • 
                

              

              

                

                  READBronze Parquetrees46/ + criteo/
                

                →
                

                  WRITE TOIceberg cataloglocal.clickstream.*
                

                →
                

                  QUERYSpark SQLcategory + event type
                

                
Output: batch/iceberg/

              

            

            

              

                PIPELINE / 03_DELTA.PY
                
Speed-layer analytical outputs

                

                  Spark partitions the full event table by event type and
                  derives query-ready Delta outputs for demand and hourly
                  activity.
                

                
    
                  
  • Events partitioned by view, cart, and purchase
    • 
                  
  • Trending products, price, and unique viewers
    • 
                  
  • Hourly volume by event type
    • 
                

              

              

                

                  READREES46 Bronze109.95M events
                

                →
                

                  DELTA EVENTSPartition by typespeed/delta/events/
                

                →
                

                  Trendingview_countHourlyevent volume
                

                
Outputs: speed/delta/

              

            

            

              

                PIPELINE / 04_HUDI.PY
                
Upsert-ready customer profiles

                

                  Spark groups events by user, builds behavioral features, and
                  writes a Merge-on-Read Hudi table keyed by user ID.
                

                
    
                  
  • Views, carts, purchases, spend, and recency
    • 
                  
  • Cart rate, purchase rate, and segment label
    • 
                  
  • Latest event used as the precombine field
    • 
                

              

              

                

                  GROUP BYuser_idevent history
                

                →
                

                  FEATURESProfile aggregaterates + segments
                

                →
                

                  UPSERTHudi MOR15.1M profiles
                

                
Output: serving/hudi/user_profiles/
